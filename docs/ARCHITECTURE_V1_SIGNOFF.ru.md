# KOMETA · Архитектура v1.0 — лист на подпись

Дата: 23.10.2026 · Статус: **утверждено владельцем 23.10.2026** (ADR-022) · Подробности: `docs/reviews/consistency-A07-2026-10-23.md`

## 1. Что делаем
3D-раннер в браузере: пять полос, прыжки через машины, полёт на баллоне «AIR», трюки, режим LIFTOFF.
Игра открывается по карточке «Сыграть» на экране заказа Искенди. Входа нет, гость просто играет, пока ждёт заказ.
Работает на телефонах, планшетах и компьютерах.

## 2. Что входит в v1
- Бесконечный заезд, авария заканчивает его. На экране итогов счёт и «Заново», плюс дистанция, время, рекорд и меню (ADR-020).
- После каждого заезда показывается уникальный промокод `ISK-XXXX-XXXX`. Он же уходит хосту в `game.runEnded`. Ценности у кода нет, смысл и оформление определим позже.
- Все бонусы: кольца, звезда (COSMONAUT), баллон AIR, капсула с RADAR, MAGNET, SHIELD, EMP.
- Машина — концепт B «Самоделка» (ADR-019). Мир — вымышленный Кометоград.
- Рекорды и достижения хранятся только на устройстве. Достижений 19: «Weekly Pilot» отложен.
- Встраивание в Искенди:
  - игра открывается в отдельном iframe, создаётся по нажатию;
  - лёгкий набор ассетов ≤ 3 МБ;
  - звук по умолчанию выключен;
  - номер заказа виден в игре; когда заказ готов, игра встаёт на паузу и показывает «Заберите заказ»;
  - начатый заезд можно продолжить позже.

## 3. Чего нет в v1
Рейтинга, сервера игры, базы данных, аккаунтов и входа. Нет облачных сохранений, «недели», кнопки «Поделиться»,
аналитики внутри игры и настоящих наград. Архитектура позволяет добавить всё это позже без переделки ядра:
симуляция детерминирована, повторы заездов записываются локально.

## 4. Схема
```
Гость ─► сайт Искенди (фронт) ─ нажал «Сыграть» ─► iframe play.iskendy.ru (статика игры)
              ▲                                         │
              └──── postMessage: статус заказа ◄────────┘ итоги заезда, промокод, ошибки
Сервер Искенди в РФ: общий Caddy ─┬─ контейнер Искенди (FastAPI + фронт) — без изменений
                                  └─ контейнер игры (только статические файлы)
```

## 5. Технологии
TypeScript, Vite, three.js (WebGL2), React 19 + Zustand для меню, детерминированная симуляция 60 Гц
в отдельном пакете. Тесты: Vitest, fast-check, Playwright. Серверной части в v1 нет.

## 6. Хостинг и выпуск (ADR-021, предложение)
- Поддомен `play.iskendy.ru` на том же сервере в РФ, за общим Caddy, в отдельном контейнере со статикой.
- CI собирает архив версии с контрольной суммой, сервер ставит закреплённую версию. Откат — вернуть прошлую версию.
- Трафик: несколько ГБ в месяц, CDN не нужен.
- Выключатель: вместо игры отдаётся страница «выключено», и хост показывает «Игра недоступна» без своего деплоя.

## 7. Что меняется у соседей
- **Фронт Искенди:** карточка «Сыграть» становится активной, плюс мост сообщений и оверлей. Нужны макеты в Figma (Q-36 фронта).
- **Бэкенд Искенди:** одна строка в CSP — origin игры в `frame-src` (Q-34 фронта). Код бэкенда больше не трогаем.
- **Конфиг Caddy:** блок для `play.iskendy.ru`, согласовать с владельцем сервера.

## 8. Безопасность и данные
Отдельный origin: игра не видит cookies, хранилище и страницу хоста. Сообщения проверяются по origin и схеме.
Персональных данных нет, cookies нет, сторонних скриптов на origin игры нет. Промокод не попадает в URL,
аналитику и логи. Секретов у игры нет.

## 9. Качество
- 60 кадров в секунду на среднем телефоне, не ниже 30 на слабом.
- Начальный JS не больше 400 КБ, первая загрузка во встраивании не больше 3 МБ.
- Проверки на каждый PR:
  - детерминизм (Node, Chromium, WebKit, Firefox);
  - честность генерации трафика;
  - e2e на 390×844 и 1440×900.
- Перед релизом iPhone Safari, Android Chrome, встроенный браузер Telegram.
