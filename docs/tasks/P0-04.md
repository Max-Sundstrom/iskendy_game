# P0-04 — Assets structure, license ledger and checks
Owner: Technical artist (done by the Orchestrator session) · Reviewers: license-auditor, code-reviewer · Phase: 0 · Depends on: P0-01, P0-02

## Goal
No file can ship without a license entry and proof (invariant 8), and no real brand name slips into shipped
names or strings (AGENTS §12).

## Scope
`assets/` (structure, empty `LICENSES.json`), `tools/assets/`, `package.json` scripts, `vitest.config.ts`,
CI step, ASSETS §4.

## Out of scope
gltf-transform pipeline and triangle/texture budgets: they need the first GLB and a pinned `@gltf-transform/cli`
(P3-01). Credits screen (P4-01).

## Acceptance criteria
1. `assets/source`, `assets/source/_licenses`, `assets/build` and `assets/LICENSES.json` exist.
2. `pnpm assets:check` fails when a shipped file has no entry, a license is not allowed, proof is missing,
   CC-BY/OFL lacks attribution, a listed file is missing or doubled, or a brand name appears.
3. CI runs `pnpm assets:check`.

## Verification
Unit tests in `tools/assets/ledger.test.ts`; manual: an unlisted `volga-taxi.glb` in `assets/build`.
