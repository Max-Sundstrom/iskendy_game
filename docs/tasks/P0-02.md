# P0-02 — CI: typecheck, lint, unit, sim, E2E smoke, bundle size
Owner: Release engineer (done by the Orchestrator session) · Reviewers: security-engineer, code-reviewer · Phase: 0 · Depends on: P0-01

## Goal
Every PR shows all checks; nothing merges red.

## Scope
`.github/workflows/ci.yml`, `tools/check-size.ts`, `package.json` script `check:size`, root tsconfig/ESLint globs.

## Out of scope
`assets:check` (arrives with P0-04), security scanners and branch protection (P0-07), previews and release
archive (P0-08), perf:smoke (P1-04).

## Acceptance criteria
1. On every PR and push to `main`: typecheck, lint (ESLint + dependency-cruiser), format check, unit, sim,
   build with bundle-size check, Playwright smoke at 1440×900 and 390×844.
2. Bundle check fails above 400 KB gzip of JS (ARCHITECTURE §12) and when any source map is in `dist`.
3. Workflow token is read-only; actions pinned by commit SHA, versions ≥ 14 days old; no third-party actions.

## Verification
Local: all commands green; `check:size` fails with a planted `.map`. Remote: first run on the PR/branch.

## Handoff note
- **What changed:** three jobs (`checks`, `build`, `e2e`) on Ubuntu 24.04 with Node from `.node-version` and
  pnpm 12.11.2 installed via npm (Corepack can't run pnpm 12 yet). Actions: checkout v7.0.1, setup-node v7.1.0,
  upload-artifact v7.0.2 (Playwright report on failure), all pinned by SHA.
- **Verified locally:** typecheck, lint, format, 22/22 tests, build, `check:size` 26.9 KB of 400 KB; a planted
  `.map` makes `check:size` exit 1.
- **Follow-ups:** P0-04 adds `assets:check` to the `checks` job; P0-07 adds gitleaks/Semgrep/CodeQL/OSV,
  Renovate and branch protection (owner action in GitHub settings).
