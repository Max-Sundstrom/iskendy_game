# P3-00 — Visual slice: detailed car and traffic, roadside, thruster vapour, launch intro
Owner: Orchestrator (render + tech-artist work, procedural) · Reviewers: art-director, perf-auditor, qa-engineer ·
Phase: 3 (pulled forward on the owner's request, ADR-026) · Depends on: P1-04, P1-05

## Goal
The owner's playtest feedback of 2026-10-23: BOOST seemed not to work, the car and world needed far more detail, the
run should start like the reference (car on a ramp, 3-2-1, go), cold-gas vapour should come from the car's nozzles,
and obstacles should be many kinds of vehicles from cars to trucks. Deliver a playable slice that answers all of it
before the Blender assets of P3-01…P3-03.

## Context
GDD §1 (img 12–14, 20), §2, §3, §5.4, §6, §7, §12, §13 · ART_DIRECTION §4–§8 · ARCHITECTURE §12 budgets · ADR-026.

`apps/web/src/engine/**`, `apps/web/src/ui/{hud,intro}.ts`, `apps/web/src/main.ts`, `apps/web/src/style.css`,

## Contract
None changed: the renderer still only reads sim snapshots. The intro runs before tick 0, so replays and hashes are
untouched.

## Acceptance criteria
1. BOOST: holding the button keeps boosting even if the thumb drifts; no iOS callout or text selection; the button
   lights while boosting; tail-thruster jets and the FOV kick show it.
2. Vapour from the nozzles: main tail jets while boosting, lift nozzles beside the wheels on the jump kick, in flight
   and on touchdown, attitude puffs on lane changes, a cloud on a crash. One draw call, no per-frame allocation.
3. Hero car: concept B "Samodelka" with a smooth lofted body, targa glass, rims, lamps and visible nozzles, in the
   Iskendi Courier livery, rolling and pitching with the motion and with a contact shadow.
4. Traffic: a distinct model for each of the 13 vehicle types, ≤ 3 000 triangles each, one draw call per type.
5. Roadside: parapets and railings, arched lamps, linden trees, the river, city blocks with lit windows, and a horizon
   with skyline, hills and the Cosmos Park rocket.
6. Intro: steel truss gantry and curved ramp, 3-2-1 synced to the descent, the premise toast, hand-over to the chase
   camera; retry plays the last 1.5 s; input buffered from "1".
7. Budgets: ≤ 150 draw calls, ≤ 300k triangles, JS ≤ 400 KB gzip.
