# P3-00B — Refine the original hero and traffic vehicles

Owner: render engineer / technical artist · Reviewers: independent art and QA · Phase: 3 · Depends on: P3-00, P1-09

## Goal

Make the hero car and traffic read as coherent, modern, finished original vehicles on the phone chase camera.
Preserve the approved Samodelka concept B, soft pontoon shoulders, two-tone Courier palette, targa roof and four round rear lamps.

## Context

Owner requested better vehicle models before the next mechanics cards. ART_DIRECTION §6–8, ADR-019/023/027,
ASSETS §5, ARCHITECTURE §12 and scenarios G2/G3 apply. Baseline screenshots are retained in
`/workspace/scratch/kometa-visual-baseline`. The existing hero measures 17,044 triangles and 13 materials,
above its 15k / 3-material budget; improve shape and material coherence while correcting this gap.

## Scope

`apps/web/src/engine/car.ts`, new `engine/hero/*`, `engine/models/{cars,heavy,parts,loft,models.test}.ts`,
hero budget tests, `apps/web/test/models.*`, and this card. Other model files only if needed for coherent shared parts.
No renderer/main/perf/sim/input changes. No new dependencies, third-party assets, brands or owner ornament.

## Contract

Frozen: `CarRig` public shape, transforms/front direction, wheel spin markers, nozzle anchors/glow and shadow.
Preserve geometry collision dimensions, C ramp, existing roof placeholder and deterministic simulation.
Traffic stays one instanced combined geometry per type using the shared palette material.

## Acceptance criteria

1. Improve hero silhouette, canopy integration, wheels/arches and rear readability; keep the original approved identity.
2. Traffic receives consistent glazing, wheels, trim and meaningful silhouette refinements, not a subdivision increase.
3. Hero geometry <=15,000 triangles and <=3 materials excluding contact shadow, each traffic model <=3,000 triangles.
4. Automated budget coverage includes hero and all traffic. Typecheck/lint/unit/build/size pass.
5. Real browser screenshots at 390x844 and 1440x900 plus rear/front/side views demonstrate changes; independent review inspects them.
6. Measure actual draw/triangle counts and run `perf:smoke` once P0-09 is available. Record unsupported or unrun checks explicitly.

## Verification

Use Node 24, pnpm 12.11.2 and system Chromium. Coordinate browser access with the orchestrator.
Publish a separate working branch and draft PR; no automatic merge or deployment.
