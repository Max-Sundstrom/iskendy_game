# P0-05 — Task cards, progress log, PR and issue templates
Owner: Orchestrator · Reviewers: code-reviewer · Phase: 0 · Depends on: P0-01

## Goal
Every task starts from a card and ends with a handoff note in its PR; bugs, feel and perf reports arrive in a
form the team can act on.

## Scope
`.github/pull_request_template.md`, `.github/ISSUE_TEMPLATE/*`, `docs/tasks/`, `docs/PROGRESS.md`.

## Acceptance criteria
1. `docs/tasks/` and `docs/PROGRESS.md` exist and are in use (A-07, P0-01, P0-03 cards; dated progress lines).
2. The PR template is the handoff note of AGENTS §9 plus the DoD checklist of §8.
3. Issue forms for bug, feel and perf ask for a scenario ID, a seed or replay, the device and the budget.

## Verification
YAML parses; GitHub shows the forms once on the default branch.

## Handoff note
- **What changed:** PR template (task, verification, DoD, tuning/SIM_VERSION, reviewers); issue forms `bug`,
  `feel` (with a tuning-delta field), `perf` (measured vs budget); blank issues disabled.
- **Verified:** all YAML files parse (Python `yaml.safe_load`); `pnpm format:check` clean.
- **Follow-ups:** labels `bug`, `feel`, `perf` are created by GitHub on first use or by the owner.
