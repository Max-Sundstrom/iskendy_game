# P2-03a — Score current actions and settle streaks deterministically

Owner: sim engineer · Reviewers: independent QA and orchestrator · Phase: 2 · Depends on: P2-02b

## Goal and scope

Apply GDD §9 points, the 2.5 s streak, multiplier, pending pot and meter to existing real gameplay events.
This is part 1 of P2-03. NEAR MISS, SMASH, RING and cone bowling lack their gameplay triggers; keep those
bindings visibly pending for subsequent cards rather than claiming the full event table is complete.
Own sim/shared scoring contracts, tuning, focused tests, goldens/both determinism fixtures and docs.
No new UI/model/mode/pickup/director mechanics, dependencies, servers, accounts or rankings. Existing HUD
and results continue reading banked score.total; full streak/meter/feed UI is P2-07.

## Frozen state and event contract

- Expand score with total, pot, streakN, streakTicksLeft, meter, boostTicks and roofDistanceM. Hash every
  future-affecting field. Integer duration counters use ceil(durationS*tickRateHz); default .25 s = 15 ticks,
  2.5 s = 150. Keep fractional points; only existing display/replay output floors the final total.
- scoreTick runs after all collisions, before director. Capture the original numeric events.count prefix;
  no readEvents or per-tick arrays/objects. Capture the starting rideSlot for roof-boundary handling.
- Append event kinds22 scoreAddedDirect,23 scoreAddedToPot (a=ScoreReason,b=actual fractional credited points),
  24 streakSettled (a=banked,b=lost),25 streakMilestone (a=N,b=0). Distance creates no per-tick event.
- ScoreReason is frozen: boost1,clear2,semiCleared3,hop4,roofRide5,frontFlip6,barrelRoll7,
  perfectLanding8,stuntLanding9,slam10. Added events must distinguish direct points from pending pot.
- Compute each award into state sequentially in original producer/traffic-slot order. Only normalize an
  adjacent road [land(slam),landingGraded] pair to grade-first, consuming grade once. HOP precedes its SLAM;
  platform rideStart.slam is ignored because land.slam already exists. Input slam/start-trick earns nothing.
- Presentation credits aggregate into preallocated 2×10 buckets, emitted direct→pot then reason order.
  This must not reorder state additions or multiplier calculations. Emit milestones after credits and before
  settlement; a milestone means a threshold was crossed even if that tick subsequently loses its pot.
- Preserve every source event while appending. Grow the preallocated event buffer to1024 with a documented
  conservative current-producer bound <570 (64 traffic slots); this structural capacity is not gameplay tuning.
  Always inspect terminal SimStatus as well as crash events. Test >32 raw triggers plus a late crash and verify
  no raw event is overwritten/dropped. New milestone outputs must remain bounded even if fireworksEvery=1.

## Frozen rules

- Distance keeps existing immediate total arithmetic. Each active streak action increments N before its
  multiplier min(cap,1+step*(N-1)) and refreshes the timer. Meter gains do not receive a multiplier and saturate
  at meter.capacity. Mode activation remains P2-04; reaching capacity must not invent invincibility here.
- Existing awards use tuning: CLEAR300/SEMI3000, HOP150, FRONT FLIP360*(1+.2*(count-1)), ROLL120,
  PERFECT120 or STUNT20, SLAM50. Extra-flip bonus is linear, points-only. Perfect/stunt are exclusive.
- Actual boosting pulses every15 default ticks. Partial interval resets when actual boost stops. Default
  target total; activePot alternative uses current multiplier only if an existing streak is active. BOOST
  never increases N, refreshes or breaks a streak. Stop/restart and insufficient AIR must be tested.
- Roof pulses every10 m while the tick starts and ends on the same valid platform. Default distance basis
  world; alternative relative uses max(0,player travel - platform travel). Reset remainder on exit/change.
  Target activePot by default; with no active streak use direct base points. Refresh an existing timer on a
  pulse without increasing N or creating a new streak, regardless of selected total/activePot ledger.
- Consume physics awards first, then boost pulses, then roof pulses. Decrement an existing streak timer once
  before current awards; an award at exact expiry can refresh before settlement (149/150/151 regression).
- Settle exactly once after staging all awards: CRASH loses the entire pot, else SCRAPE banks configured
  ratio0, else SLOPPY banks50%, else timeout banks100%. A late crash overrides earlier sloppy/scrape/expiry.
  Same-tick late awards cannot reopen a broken streak. Previous banked total and direct distance remain.
- New tuning: scoring.boostIntervalS=.25,roofRideIntervalM=10,boostTarget='total',roofRideTarget='activePot',
  roofRideDistanceBasis='world'; target enum total|activePot; distance enum world|relative;
  streak.scrapeBankRatio=0. Record ambiguous policies in DECISIONS/GDD as explicit proposed defaults/flags.
  Do not change the four deferred tuning proposals or presentation tuning.
