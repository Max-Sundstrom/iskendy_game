# P1-05 — Input mapper, minimal HUD, results with promo code, Retry
Owner: UI engineer (done by the Orchestrator session) · Reviewers: code-reviewer, qa-engineer · Phase: 1 · Depends on: P1-04

## Goal
A playable loop on phones and desktops: steer by swipe or keys, see score, distance and AIR, crash, read the
results with the promo code, and go again.

## Context
GDD §4 (controls, input feel), §9 (distance points), §14 (HUD), §15.4 (results); ADR-020 and Q16 (promo code);
SCENARIOS J14, P1; EMBEDDING §4 (Russian first in the host).

## Scope
`apps/web/src/{main.ts,style.css}`, `apps/web/src/input/*`, `apps/web/src/ui/*`, `apps/web/src/platform/*`,
`packages/content/i18n/{ru,en}.json`, sim `score.total`, e2e `run.spec.ts`, Playwright timeouts.

## Acceptance criteria
1. E2E: start → crash → retry on both viewports (1440×900, 390×844 touch).
2. Keyboard and swipe change lanes; up-swipe held = fly; BOOST button held = boost.
3. Results show score, NEW BEST, distance, time and an `ISK-XXXX-XXXX` code; Retry starts a new run at once.

## Handoff note
- **What changed:**
  - **Input:** one controls aggregator with a latch, so a tap shorter than a frame is never lost; keyboard by
    `code` (layout-independent, no auto-repeat); touch swipes per GDD §4 (up-swipe holds Jump until the finger
    lifts); BOOST hold button for touch.
  - **HUD:** DOM binder that writes only changed values.
  - **Results:** cause line, score, NEW BEST (local best in versioned storage, failures tolerated), distance,
    time, promo code from `crypto.getRandomValues` in Crockford Base32, Retry (button, Enter, Space).
  - **Language:** Russian by default (`?lang=en` for checks; the host locale arrives with P5-09).
  - **Sim:** `score.total` counts distance (GDD §9).
- **Verified:**
  - typecheck, lint, format, 84 tests (promo format and alphabet property, CSPRNG uniqueness, normalisation,
    best-score storage, swipe classification, input latch);
  - E2E 8/8 on the dev server and 10/10 against the container (headers OK, no CSP or Trusted Types violations);
  - screenshots of HUD and results at 390×844;
  - JS 172 KB gzip.
- **Found and fixed:**
  - promo normalisation turned the I of "ISK" into 1 (caught by its test);
  - the hint overlapped the BOOST button;
  - synthetic swipes in E2E were stretched past 180 ms by slow software frames, so they are now dispatched in
    one task;
  - three r186 dropped PCFSoftShadowMap.
- **Goldens:** determinism `cb0aae87-91cfb58f` (score added), logged in the sim changelog.
- **Follow-ups:**
  - P1-06: replays and golden replays across engines;
  - P4: real fonts (subset, ledger), menus, pause screen;
  - P5-09: `game.runEnded` with the promo code to the host.
