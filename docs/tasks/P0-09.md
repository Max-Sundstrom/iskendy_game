## Contract

Frozen: diagnostics observe actual renderer.info and real rendered frame durations, without changing sim
outcomes or bypassing collisions. Use the real game with a fixed seed and intro=0; drive actual controls and
retry naturally on crash. Default measurement lasts approximately 90 seconds. Report whether the duration
is wall or simulated time, sampled frames, active-play coverage and run/retry counts. Reject empty samples.
Timing in software-rendered cloud Chromium is informational, never claimed as phone performance.
Hard geometry budgets: max draw calls150, visible triangles300000. No weakening budgets. CSP remains strict:
replace existing overlay inline CSS with a class. No per-frame allocations in the collection hot path.

## Acceptance criteria

1. Command launches/owns a local server unless an explicit URL is provided; cleans up browser/server on success
   and failure. Uses existing Playwright and optional PW_CHROMIUM_EXECUTABLE; no new packages.
2. Fixed seed/scripted input, recorded viewport/quality/browser/environment and a JSON report with p50/p95,
   max draws/triangles, sample coverage; include heap/bundle data when available and label omissions.
3. Fail nonzero on browser/page/CSP failures, empty or inactive measurement, or exceeded geometry budgets.
4. Optional baseline comparison can gate deterministic geometry regression (>10%); do not gate cloud frame ms.
5. A complete 90-second run and meaningful failure-path checks are independently verified; screenshots at
   desktop and mobile. Short smoke mode may be used for development but cannot replace the full report.
