# P0-01 — Monorepo, strict TypeScript, lint, tests, boundaries
Owner: Orchestrator · Reviewers: code-reviewer, qa-engineer · Phase: 0 · Depends on: Phase A (ADR-022)

## Goal
A pnpm workspace where every agent can run `pnpm typecheck`, `lint`, `test` and `test:e2e`, with the module
boundaries of ARCHITECTURE §2 enforced and proven.

## Context
ROADMAP P0-01; ARCHITECTURE §2, §13; AGENTS §3–§6; SECURITY T15 (14-day minimum release age). Owner approved the
P0 dependencies on 2026-10-23.

## Scope
Root configs, `apps/web` (placeholder page), `packages/{sim,shared,content}` package manifests and placeholders,
`tests/`, `e2e/`, `docs/DECISIONS.md` (pinned versions), README setup note.

## Out of scope
CI workflows (P0-02), zod tuning schema (P0-03), asset pipeline (P0-04), templates (P0-05), security tooling
(P0-07), React/three/zod and other runtime libraries (added by the tasks that use them).

## Contract
None frozen. `@kometa/sim` exports `SIM_VERSION`; `@kometa/shared` exports `SCHEMA_VERSION`.

## Acceptance criteria
1. `pnpm typecheck`, `pnpm lint`, `pnpm test` are green on the empty packages.
2. Each boundary rule has a fixture in `tests/fixtures/boundaries/` that fails, asserted by `tests/boundaries.test.ts`:
   sim → presentation libs, sim → outside sim/shared/content, UI → engine internals, and the sim determinism lint
   rules (`Math.random`, transcendental `Math`, `Date`, `performance`).
3. `packages/sim` compiles without DOM or Node types.
4. Playwright smoke passes at 1440×900 and 390×844 (touch).
5. Versions are exact, at least 14 days old, and recorded in DECISIONS.

## Verification
`pnpm typecheck && pnpm lint && pnpm test`, `pnpm format:check`, `pnpm build`, `pnpm test:e2e`.
