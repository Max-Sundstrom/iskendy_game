# P1-01 — Sim core: state, fixed step, RNG, LUT maths, lanes, speed curve, lane change
Owner: Sim engineer (done by the Orchestrator session) · Reviewers: code-reviewer, qa-engineer · Phase: 1 · Depends on: P0-03

## Goal
The deterministic heart of the game: one fixed 60 Hz step that moves the car forward on the speed curve and between
five lanes, identical in Node and the browser.

## Context
GDD §4 (input feel), §5.1–5.2; ARCHITECTURE §3, §4.1–4.4, §4.6; AGENTS invariants 1–7; tuning keys `sim.tickRateHz`,
`sim.lanes.*`, `sim.speed.minMps/maxMps/distanceScaleM`, `sim.world.originShiftM`.

## Scope
`packages/sim/src/{rng,tables,math,input,events,state,step,hash,testing}.ts` and tests, `packages/shared/src/events.ts`,
`tools/gen-tables.ts`, `apps/web/test/` (dev-only probe), `e2e/determinism.spec.ts`, ESLint test override.

## Contract
`createSimState(seed, tuning)`, `step(state, heldMask, tuning)`, `stateHash(state)`, `Action` bits, `SimEventKind`
codes (append-only), `readEvents(buffer)`. Lane space: +x is the driver's right, lane 0 is the leftmost. Frozen:
no (P1-02/03 extend the state).

## Acceptance criteria
1. Unit tests for lanes, timing, queueing (G1, G2), speed curve, origin shift.
2. A 10 000-tick hash is identical in Node and Chromium.
3. No `Math.random`, clocks or transcendental `Math` in the sim; the speed curve uses a checked-in, pinned table.

## Verification
`pnpm typecheck && pnpm lint && pnpm test`, `pnpm test:e2e` (determinism spec).

## Handoff note
- **What changed:**
  - sfc32 seeded by splitmix32, cross-checked against an independent Python implementation;
  - `SAT_EXP` table (513 samples of 1 − e^(−u), generated by `tools/gen-tables.ts`, hash-pinned), linearly
    interpolated (error ≤ 3·10⁻⁵, ≈ 0.002 m/s on speed);
  - lane change: ease-out cubic, 0.16 s, so it completes on the 10th tick; one queued input; edge bump;
    left + right on the same tick cancel out;
  - speed curve; origin shift every 2 000 m with an event;
  - preallocated numeric event buffer (no allocation per step);
  - FNV-1a 32 state hash over quantised fields; scripted input generator at `@kometa/sim/testing`.
- **Verified:**
  - all checks green, 53 tests: unit, fast-check properties (bounded and finite state for any input; same
    seed + inputs ⇒ same hash);
  - 10 000-tick golden `eb26e68b` in Node, and the same hash in Chromium through `e2e/determinism.spec.ts`.
- **Tuning keys / SIM_VERSION:** none added / 1.
